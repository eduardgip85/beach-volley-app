Edge Functions

¿Por qué no llamar a Gemini desde React?

Frontend directo

  • Expone API keys
  • Difícil controlar abusos
  • Resultado manipulable

Edge Function

  • API key privada
  • Validación de usuario
  • Rate limit semanal
  • Update seguro en Supabase

Código relevante

Service de verificación


export async function verifyEquipmentImage(imageFile, target) {
  if (imageFile.size > 3 * 1024 * 1024) {
    throw new Error("Image must be smaller than 3MB");
  }

  const base64 = await fileToBase64(imageFile);

  const { data, error } = await supabase.functions.invoke(
    "verify-equipment",
    { body: { image: base64, target } }
  );

  if (error) throw error;
  return data;
}
